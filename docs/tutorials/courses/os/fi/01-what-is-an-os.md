# Mitä käyttöjärjestelmä tekee?

Copyright (c) 2026 ItsDropper. MIT-lisenssi; katso projektin juuren `LICENSE`.

Käyttöjärjestelmä hallitsee laitteita ja resursseja sekä tarjoaa ohjelmille yhteisiä palveluita. Kernel toimii järjestelmän keskeisenä osana. Sen ympärillä voi olla ajureita, palveluita, komentotulkki ja graafinen käyttöliittymä.

VNTOSissa on käynnistys, konsoli, keskeytyksiä, muistinhallinnan alkuvaiheita ja kokeiluja usealla CPU-ytimellä. Siinä ei vielä ole yleistä prosessieristystä, tiedostojärjestelmää eikä valmista tehtäväajastinta. Älä sekoita suunniteltuja ominaisuuksia jo toteutettuihin.

**Pohdi:** Nimeä kolme asiaa, joita kernel hallitsee, ja yksi ominaisuus, jota VNTOSissa ei vielä ole.
