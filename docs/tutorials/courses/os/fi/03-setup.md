# Turvallisen kehitysympäristön valmistelu

Copyright (c) 2026 ItsDropper. MIT-lisenssi; katso projektin juuren `LICENSE`.

VNTOS rakennetaan projektin omalla build-skriptillä. Aja projektin juurihakemistosta `bash os/build.sh` ja lue ensin projektin README sekä skriptin vaatimat työkalut. Jos jokin työkalu puuttuu, selvitä se ennen lähdekoodin muuttamista.

Käytä kokeisiin QEMUa. Älä käynnistä keskeneräistä kerneliä oikealla laitteistolla, älä ylikirjoita levyjä äläkä tee useita muutoksia kerralla. Säilytä Gitissä palautettava tila.
