# Sarjaportin komentotulkki

Copyright (c) 2026 ItsDropper. MIT-lisenssi; katso projektin juuren `LICENSE`.

Shell lukee komennon, tunnistaa sen nimen ja kutsuu vastaavaa toimintoa. VNTOSin shell on kernelin osa, joten virhe siinä voi vaikuttaa koko järjestelmään.

Avaa `os/kernel/shell.vnt`. Seuraa syötteen lukemista, komentorivin käsittelyä, komentojen vertailua ja tulostusta. Tutki olemassa olevia muisti- ja SMP-komentoja. Mieti uutta komentoa suunnitellessa myös virhetilanteet ja tuntemattomat komennot.

**Pohdi:** Miten shell muuttaa tekstin toiminnoksi? Miksi tuntemattomasta komennosta pitää kertoa käyttäjälle?
