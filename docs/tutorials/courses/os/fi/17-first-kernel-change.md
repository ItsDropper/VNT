# Ensimmäinen pieni kernel-muutos

Copyright (c) 2026 ItsDropper. MIT-lisenssi; katso projektin juuren `LICENSE`.

Valitse pieni, palautettava muutos, jonka toiminta voidaan todentaa. Ennen muokkausta selvitä, missä toiminto toteutetaan, mitä se kutsuu, miten onnistuminen näkyy ja mitä virhetilanteita pitää käsitellä.

Hyvä ensimmäinen tehtävä voi olla shellin selkeämpi virheilmoitus tai dokumentaatiokorjaus. Tee yksi muutos, rakenna kernel ja tarkista tulos. Jos testi epäonnistuu, selvitä syy ennen seuraavaa muutosta.

**Pohdi:** Ehdota pientä muutosta ja nimeä testi, jolla todistaisit sen toimivan.
