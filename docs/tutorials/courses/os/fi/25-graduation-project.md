# Loppuprojekti: paranna yhtä alijärjestelmää

Copyright (c) 2026 ItsDropper. MIT-lisenssi; katso projektin juuren `LICENSE`.

Valitse yksi pieni, oikea ongelma ja tee siihen testattava parannus. Voit selkeyttää shellin virheilmoitusta, lisätä testin muistinhallinnan nykyiselle polulle, dokumentoida moduulin rajapinnan tai lisätä CI-tarkistuksen tunnettua regressiota varten.

Määrittele tavoite ennen koodaamista. Selvitä nykyinen toteutus ja virhetilanteet. Lisää testi, joka tarkistaa todellisen käyttäytymisen. Dokumentoi myös rajoitukset: kernelissä ominaisuus ei ole valmis vain siksi, että lähdekoodi kääntyy.

**Pohdi:** Kirjoita projektin tavoite yhdellä lauseella ja nimeä testi, joka osoittaa onnistumisen.
